# Ascend Browser

Ascend Browser is a privacy-first browser in the family of firefox rebuilt using Rust.

## Prerequisites

- Rust (>= 1.60)
- Cargo
- Tokio

## Installation

1. Clone the repository:
    ```sh
    git clone https://github.com/yourusername/ascend-browser.git
    cd ascend-browser
    ```

2. Build and bundle the project:
    ```sh
    make
    ```

3. Run the installer (assuming it's in `downloads` directory):
    ```sh
    ./downloads/ascen-installer.exe
    ```
